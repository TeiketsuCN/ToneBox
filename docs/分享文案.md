## 一句话

ToneBox：一个 Windows 上的「格式顾问」——判断你手上的音频/视频是什么、该转成什么，顺带管理音乐库、试听和批量转码。

## 论坛/B站简介长版

ToneBox 是一个 Windows 桌面工具，定位不是「转换按钮」，而是格式顾问：

- 拖进文件先告诉你它真实是什么：编码、采样率、位深、是不是假无损
- 音乐库：歌曲/专辑/风格/艺术家，本地只读扫描
- 播放：WASAPI 独占直通、按源采样率、ReplayGain；播放栏可拖动/拉伸/收起
- 视频：MKV/MP4/WEBM/AVI，保留第一条画面 + 全部音轨
- 设备：输出/输入、耳机/蓝牙/HDMI/USB，Steam/Realtek/NVIDIA/FxSound 标记
- 默认极光主题，MIT 开源

## 分享注意

- **发 Release 链接，不要发仓库的 Code → Download ZIP**：那个只有源码，没有 exe。
- 国内访问 GitHub 慢/打不开时，可以把 `ToneBox-beta1.0-win64.zip` 传到 123 云盘/阿里云盘/蓝奏云，再发网盘链接；GitHub 保留为源码和更新地址。
- 不要改包里的 `ffmpeg\` 目录结构；不要只发 exe（会缺 ffmpeg）。
- 对方第一次运行如果被 SmartScreen/杀软拦：这是未签名测试版，选择「仍要运行」或加信任；不放心就别跑。
