# 打包与分发

## 结论：分两步走

| 阶段 | 位置 | 状态 |
|---|---|---|
| **现在**（迭代期） | `D:\Apps\FormatConverter\` 免提权安装 | ✅ 已实现 |
| **发布期**（给外人用） | `C:\Program Files\` + 安装程序 | ⏳ 等 v1.0 |

### 为什么现在不进 Program Files

写 `Program Files` 需要管理员权限。开发期每改一行代码、重新编译、部署，就弹一次 UAC。
**Program Files 是发布版待的地方，不是每天改的版本待的地方。**

现在的做法保留了所有"正规软件"的外观，但不提权：

- 固定安装目录（不是开发目录，`cargo clean` 不会弄坏它）
- 桌面 + 开始菜单快捷方式
- 「应用和功能」里有卸载项
- 有版本号文件

## 目录结构

```
D:\Apps\FormatConverter\
├── format-converter.exe    主程序（3.2 MB，单文件）
├── version.txt             版本与安装时间
├── uninstall.ps1           卸载脚本
└── ffmpeg\                 预留：放了 ffmpeg.exe + ffprobe.exe 就优先用它
```

`ffmpeg\` 目录不是摆设——`fc_core::locate()` 的查找顺序是：

```
程序同目录 → 同目录\ffmpeg\ → WinGet Links → C:\ffmpeg\bin → PATH
```

**所以以后想做成完全绿色版，把 ffmpeg 塞进那个目录就行，不用改代码。**

## 命名策略

- **exe 用 ASCII**：`format-converter.exe`——避免某些工具处理中文文件名出问题
- **快捷方式用中文**：`格式转换器.lnk`——用户看到的是中文

## 日常操作

```powershell
# 改了代码，重新装一遍（构建 + 拷贝 + 刷新快捷方式）
powershell -ExecutionPolicy Bypass -File D:\FormatConverter\tools\install.ps1

# 卸载
powershell -ExecutionPolicy Bypass -File D:\Apps\FormatConverter\uninstall.ps1
# 或者：设置 → 应用 → 已安装的应用 → 格式转换器 → 卸载
```

## 发布期怎么进 Program Files

需要写一个 Inno Setup 脚本（免费的 Windows 安装包工具），产物是一个 `Setup.exe`：

- 装到 `C:\Program Files\FormatConverter\`（提权一次，装机时正常）
- 开始菜单 + 桌面快捷方式（可选）
- 标准卸载项
- 可以带**可选组件**：是否顺带安装 ffmpeg（LGPL 构建，需附许可与源码链接）
- 可以签代码签名证书（避免 Defender 误报，见 `docs/法律边界-重新评估.md`）

这一步等真正要发给别人时再做，不着急。

## 还缺的三件事（打包角度）

1. **exe 没有图标**——现在是默认的灰色程序图标，在「应用和功能」里显示很丑
2. **exe 没有版本资源**——右键属性里看不到版本号、公司、描述
   （这两条可以用 `winresource` crate 在 `build.rs` 里嵌进去，半小时的活）
3. **没有代码签名**——新编译 + 调子进程 + 大量读写媒体文件，是 Windows Defender 误报的经典配方
   需要证书（约 ¥1000~2000/年），免费项目的现实选择是先不签，但要在 README 里写清楚
