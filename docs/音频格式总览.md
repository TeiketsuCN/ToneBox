# 音频格式总览（格式百科底座）

> 2026-11-08 初版。用途：格式百科的内容源 + DRM 指纹库的覆盖面清单 + 转换引擎的能力边界表。
> **"所有格式"是不可穷尽的目标**——公开标准约有 280 项，私有/平台格式每年还在新增。本表覆盖公开已知者，私有格式逐项标注"需采样验证"。

## 分级口径（本项目的处理能力）

| 级 | 含义 | 产品行为 |
|---|---|---|
| **A** | 能解码 + 推荐作为输出 | 直接转 |
| **B** | 能解码，但不推荐编码（专利/质量/无意义） | 转，附说明 |
| **C** | 只能识别，不能解码（加密/需硬件密钥） | 报身份 + 解释 + 合法出路 |
| **D** | 连身份都难判断（未知私有格式） | 报"未知加密/未知容器" + 熵特征 |
| **X** | 不是音频数据（序列/谱面/工程文件） | 归到"音乐工程"类，不做转换 |

## 14. 对本项目的一句话总结

| 分级 | 数量级 | 产品行为 |
|---|---|---|
| **A** | 约 30 种 | 直接转，是核心能力 |
| **B** | 约 70 种 | 能转，附说明（专利/质量警告） |
| **C** | 约 20 种 | **只识别 + 解释**，这是差异化 |
| **D** | 约 60 种 | 只报"未知/私有"，附熵特征 |
| **X** | 约 40 种 | 归到"音乐工程"，不做转换 |

**用户真正会遇到的，90% 集中在这 12 种**：MP3、FLAC、AAC/M4A、WAV、OGG、Opus、WMA、ATRAC(.oma/.at3)、APE、ALAC、AIFF、以及各种加密的 `.ncm`/`.mflac`。

先把这 12 种做到"识别 100% + 转换 100% + 解释到位"，再谈其余。
