# 百科长文案草稿（16 条，80~150 字）

## lossy.rs（12 条）

### AAC
1997 年 MPEG-2 提出，后来成为 MPEG-4 的核心音频编码，用心理声学在低码率下保音质。手机、流媒体、视频音轨到处都有，.m4a 里可能装 AAC 也可能是 ALAC。坑是专利池仍在收费，老设备对封装支持不一。和 MP3 比它效率更高，和 Opus 比低码率稍弱但兼容面更广。

### AC-3
1992 年随 Dolby Digital 进影院，后来成为 DVD 的 5.1 标准，固定 48kHz、码率 192~640kbps。老 DVD、蓝光、电视音轨常见。坑是多声道码率不能和立体声 MP3 直接比，dialnorm 还会改响度。和 E-AC-3 比它兼容好但效率低；老设备选 AC-3。

### E-AC-3
2004 年的 Dolby Digital Plus，AC-3 的继任者，为蓝光、流媒体和 ATSC 设计，同码率效率更高、声道更多。常见于 MP4/MKV 和流媒体，老设备不一定认。坑是它常没有独立扩展名，容易和 AC-3 混。新设备优先 E-AC-3，老 DVD/车载还是 AC-3 稳。

### WMA
1999 年微软随 Windows Media 推出，想在低码率市场对抗 MP3，Windows 和便携播放器很常见。坑是 .wma 下可能是 v2、Pro、Lossless 甚至 Voice，必须看 codec；部分老文件还有 DRM。和 MP3 比它更小但兼容差，和 AAC 比它没赢下移动端。

### WMA Pro
2003 年随 Windows Media 9 推出，定位多声道/高码率，支持 5.1 和 24bit。微软想进家庭影院，但硬件和片源没铺开，只在小众 Windows 环境存在。坑是扩展名仍叫 .wma，普通播放器不一定能解。多声道 Windows 文件才考虑它，否则选 AC-3 或转 FLAC。

### Musepack
1999 年从 MP2 派生的有损格式，SV7/SV8 两代，用较高码率追求“听不出差别”，2000 年代在发烧友圈有点名气。坑是编码器闭源、硬件支持少，SV7 和 SV8 还不兼容；现在基本没有生态。和 MP3 比它同码率口碑好，和 Opus 比它已是历史格式。遇到只解码，别指望转回去。

### Speex
2002 年 Xiph.Org 的开源语音编码，基于 CELP，主打 8/16/32kHz 低码率语音，早期 VoIP 用过。坑是它只为语音设计，不适合音乐；.spx 常包在 Ogg 里，普通播放器不一定认。和 AMR 比它开源跨平台，和 Opus 比它已被取代。只适合解出人声，别当音乐格式。

### AMR-NB
1999 年 3GPP 的窄带语音编码，8kHz、4.75~12.2kbps，是功能机和早期手机录音的主力，诺基亚、S60、3GP 里到处都是。坑是频带只到 4kHz，听感就是电话音，而且多为单声道。和 AMR-WB 比它更窄但兼容更老，和 Opus 比它是运营商时代标准。只适合听清人声。

### AMR-WB
2001 年 3GPP 的宽带语音编码（G.722.2），16kHz、6.6~23.85kbps，是 VoLTE 前的高清通话主力，比 AMR-NB 清楚。坑是它仍是语音，不是音乐；.awb/.3gp 都可能，老设备可能只认 NB。和 AMR-NB 比它频带翻倍，和 Opus 比它更老。只用于语音。

### RealAudio (Cook)
1997 年 RealNetworks 的 RealAudio 编码，靠 RealPlayer 在窄带互联网做流媒体。坑是 .ra/.rm 只是容器，里面可能是 Cook、ATRAC3、MP3，必须看 codec；音质和现代格式没法比。和 AAC 比它属于 RealPlayer 时代。只解码。

### HE-AAC
2003 年出现的 AAC 扩展，用 SBR 在低码率下重建高频，HE-AACv2 再加参数立体声，数字广播、流媒体和老手机音乐服务常用。坑是 SBR 造出来的高频会让频谱截止法误判，所以本项目输出“不可判定”；profile 有时只写 AAC。低码率选 HE，高码率选 AAC-LC。

### xHE-AAC
2019 年定稿的 MPEG-D USAC，AAC 系最新一代，目标是把低码率流媒体/广播做得更高效。坑是普通 AAC 解码器不一定支持，频谱截止法同样失效，本项目输出“不可判定”；生态还新，老设备基本不认。和 HE-AAC 比它更低码率，和 Opus 比它更偏广播。只解码。

## device.rs（4 条）

### ATRAC1
1992 年索尼 MiniDisc 的初代编码，MD SP 固定 292kbps、44.1kHz，把 CD 压到约五分之一。坑是 .aea 是 MD 导出容器，.oma 可能是加密 OpenMG；它只有 292k 一档。和 ATRAC3 比它码率高、容量小；和 MP3 比它是索尼封闭生态。只解码。

### ATRAC3
1999 年索尼为 MDLP 推出的编码，66/105/132kbps 三档，让一张 MD 装更多歌。坑是 .oma 里可能是 ATRAC3 或 ATRAC3+，还可能是加密 OpenMG；同族不同码率截止频率差异很大。和 ATRAC1 比它容量大但音质妥协，和 ATRAC3+ 比它效率低。只解码。

### ATRAC3+
2003 年索尼的 ATRAC3+，Hi-MD、Walkman、PSP 都用过，码率 48~352kbps，同码率比 ATRAC3 明显好。坑是扩展名仍是 .oma/.at3/.aa3，和 ATRAC3 混在一起；.oma 有加密和不加密两种。和 ATRAC3 比它低码率更强。只解码。

### ATRAC9
2013 年索尼为 PS4/PS Vita 推出的编码，.at9，定位游戏和便携设备的高效率有损。它比 ATRAC3+ 新，但生态只限索尼平台。坑是专利仍在保护期，本项目只做识别，不承诺解码；普通播放器基本不认。和 ATRAC3+ 比它效率更高但更封闭，和 Opus/AAC 比没有跨平台生态。
