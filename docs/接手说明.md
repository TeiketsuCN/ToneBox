| GitHub token | 用 `git credential fill` 取：`("protocol=https`nhost=github.com`n`n" \| git credential fill)` |

### GitHub 操作的固定写法

```powershell
$git = 'C:\Program Files\Git\cmd\git.exe'
$P = 'http://127.0.0.1:7890'
$tok = ((("protocol=https`nhost=github.com`n`n" | & $git credential fill 2>&1) |
         Where-Object { $_ -like 'password=*' }) -replace '^password=', '')
$h = @{ Authorization = "Bearer $tok"; 'User-Agent' = 'ToneBox'; Accept = 'application/vnd.github+json' }

# 推送（必须带 proxy，否则 443 被重置）
& $git -C $root -c "http.proxy=$P" -c "https.proxy=$P" push github main

# API（发中文 JSON 必须先转字节，否则全变 "?"）
$bytes = [System.Text.Encoding]::UTF8.GetBytes($json)
Invoke-RestMethod -Method Post -Uri 'https://api.github.com/...' -Headers $h -Body $bytes `
  -ContentType 'application/json; charset=utf-8' -Proxy $P
```

## 5. 约定与坑（血泪版）

1. **`.ps1` 必须带 UTF-8 BOM**。编辑工具会剥掉 BOM，改完必须补：
   ```powershell
   $t = [IO.File]::ReadAllText($p, [Text.Encoding]::UTF8)
   [IO.File]::WriteAllText($p, $t, (New-Object Text.UTF8Encoding($true)))
   ```
   否则 PowerShell 5.1 按 ANSI 读，中文全乱、语法报错。
2. **`.rs` 文件 CRLF/LF 混杂**：PowerShell 的多行 `-replace`/`.Replace` 经常匹配不上。
   → 优先用 `edit` 工具；必须用脚本时，**按行号插入**而不是整段替换。
3. **`Invoke-RestMethod` 发字符串 body 会按 ASCII 编码**：中文变 `?`。必须 `UTF8.GetBytes()`。
4. **`--version` / `--help` 现在是 CLI 参数**（1.4.1 加的）：更早的版本传 `--version` 会直接开 GUI 并挂住，只能读 `VERSION` 常量；`--help` 列出全部命令行开关。
5. **截图**：GUI 是全屏窗口，用 PowerShell GDI + `EnumWindows` 取最大可见窗口再 `CopyFromScreen`；`MainWindowHandle` 会取到 16×16 的辅助窗口。
6. **改格式表后必须**：`cargo test -p fc-core`（有测试会断言容器清单、旋钮表、位深表），失败通常是"忘了同步某个映射"。
7. **发布前**：`--formats` 计数、`--tools` 全绿、打包后重新下载校验 SHA256（三次一致：本地 / GitHub digest / 重下）。
8. **别把 `build/` 提交**（.gitignore 已加；历史上曾误提交 15052 个文件）。
9. **ffmpeg 命令行细节**：`wavpack -b384` 必须连写；`.snd` 要 `-f au`；`ofr --encode in.wav --output out.ofr --preset N`；`mpcenc --standard --silent in.wav out.mpc`。
10. **MXF 只接受 48kHz**：音频必须重编码成 PCM 48k，不能 copy（代码里已处理）。
11. **libgme 漏了 `zlib1.dll`**：`build-ffmpeg.sh` 的 ldd 收集只认 `lib*.dll`，而 libgme 依赖
    `zlib1.dll`；漏了它 ffmpeg 一启动就 0xC0000135。脚本里已显式补拷，别再删。
12. **芯片音乐没有固定时长**：libgme 会一直渲染（test.nsf 能出 3.4 小时），
    转换时按 `fc_core::CHIPTUNE_SECONDS`（180 秒）截断，探测也按 180s 兜底。

### 明确没做的（别承诺）

- HE-AAC / HE-AAC v2 / AAC-ELD / AAC-LD：需要 libfdk-aac（非自由），只做的话得用户自装且有许可风险
- APE / TAK / WMA Lossless / DSD（DSF/DFF）/ AIFC / BW64 输出：没有可用编码器或 muxer，已归入"只读参考"
- 多画面/多角度视频、DRM、流媒体下载：产品红线，不做

## 7. 红线

- 不解 DRM、不联网、不上传用户文件
- 不假装支持：没有编码器就灰显并解释
- 许可保持干净：程序 MIT，随包 ffmpeg 为 LGPL v3（`--disable-gpl`），`ofr.exe` 不再分发
- 用户说过"不用推 GitHub 先"的时候不要推；发版前确认
