# 把 ToneBox 工作区搬到另一台电脑

> 目标：新机器上能编译、能装、能继续开发；旧机器上不用留什么。
> 整个过程 ≈ 15 分钟（不算下载 Rust/ffmpeg 的时间）。

## 0. 要搬什么

| 内容 | 路径 | 大小 | 带不带 |
|---|---|---|---|
| 源码 + 文档 | `D:\FormatConverter`（除下面几项） | ~10 MB | ✅ 必带 |
| git 历史 | `D:\FormatConverter\.git` | 17 MB | ✅ 建议（不然没提交记录） |
| ffmpeg | `D:\FormatConverter\vendor\ffmpeg` | 152 MB | ✅ 必带（或新机跑 `tools\fetch-ffmpeg.ps1`） |
| 测试样本 | `D:\FormatConverter\samples` | 57 MB | 可选 |
| 用户配置 | `%APPDATA%\FormatConverter\config.json` | < 1 MB | 可选（配置 1/2/3、预设、库缓存） |
| 编译产物 | `target\` | **4 GB** | ❌ 别带，机器相关，会出怪错 |
| 截图 | `out\` | 104 MB | ❌ 别带 |
| 旧构建 | `app\` | — | ❌ 别带 |
| 已安装的程序 | `D:\Apps\FormatConverter` | — | ❌ 新机重装 |

## 1. 旧机器：打包

```powershell
powershell -ExecutionPolicy Bypass -File D:\FormatConverter\tools\pack-for-transfer.ps1
```

默认生成 `桌面\FormatConverter-transfer.zip`（约 100–150 MB）。需要样本就加 `-WithSamples`，
想放到 U 盘就加 `-Out E:\ToneBox-transfer.zip`。

脚本内部就是 `robocopy` 排除 `target / out / app`，再 zip；不想用脚本也可以手动：

```powershell
robocopy D:\FormatConverter E:\ToneBox /E /XD D:\FormatConverter\target D:\FormatConverter\out D:\FormatConverter\app
```

> 如果你更想用 git 搬：`git bundle create ToneBox.bundle --all`（17 MB，含历史），
> 到新机器 `git clone ToneBox.bundle ToneBox`。但 `vendor\ffmpeg`、`samples` 在 `.gitignore` 里，
> 还得单独拷或用 fetch 脚本。

## 2. 新机器：装工具链

### 2.1 Rust（必须是 **gnu** 工具链）

项目用的是 `x86_64-pc-windows-gnu`，不是默认的 msvc。

- 包里带了 `tools\rustup-init.exe`：

  ```powershell
  .\tools\rustup-init.exe -y --default-host x86_64-pc-windows-gnu --profile minimal
  ```

- 已经装过 rustup 的话：

  ```powershell
  rustup toolchain install stable-x86_64-pc-windows-gnu
  rustup default stable-x86_64-pc-windows-gnu
  ```

### 2.2 MinGW（WinLibs）——gnu 目标要它的链接器

```powershell
winget install BrechtSanders.WinLibs.POSIX.UCRT
```

装完把 `build.ps1` 里那行路径改成新机器的实际路径（见第 3 步）。

### 2.3 可选：ATRAC 外部编码器

```powershell
powershell -ExecutionPolicy Bypass -File tools\fetch-atracdenc.ps1
```

## 3. 改掉写死的路径（**必须**）

这套脚本是当年在一台机器上写的，路径是写死的：

| 文件 | 要改什么 |
|---|---|
| `build.ps1` | `C:\Users\23501\...\mingw64\bin` → 新机器的 WinLibs `mingw64\bin`；`Set-Location "D:\FormatConverter"` → 新路径 |
| `tools\install.ps1` | `$AppDir`（装到哪，如 `C:\Apps\FormatConverter`）、`$built`（release 产物路径） |
| `tools\uninstall.ps1` | `$AppDir` |
| `tools\fetch-ffmpeg.ps1`、`fetch-atracdenc.ps1` | `$AppDir` |

**最省事的办法**：把项目放在新机器的 `D:\FormatConverter`、装到 `D:\Apps\FormatConverter`，
那 install/uninstall 都不用改，只要改 `build.ps1` 里的 WinLibs 路径和 `Set-Location`。

## 4. 编译 + 安装

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File tools\install.ps1
```

脚本会：release 构建 → 复制 exe 和 `vendor\ffmpeg` 到 `$AppDir` → 建桌面/开始菜单快捷方式
（ToneBox）→ 写卸载项。

## 5. 可选：把用户配置也带过去

复制旧机器的：

```
%APPDATA%\FormatConverter\config.json
```

到新机器同一位置。里面有：配置 1/2/3（含各自参数和用户预设）、界面缩放、HDR 开关、
库文件夹列表、**音乐库扫描缓存**。

注意：库里的路径（如 `D:\FLAC`）和样本路径在新机器上可能不存在——进「库」删掉旧目录、
重新「添加文件夹」+「重新扫描」即可。

## 6. 坑清单

- **别复制 `target\`**：4 GB，而且里面有绝对路径，拷过去经常出现莫名其妙的链接错误。
- **`.gitignore` 排除了 `*.exe`、`/vendor`、`/samples`**：用 `git clone` 拿不到 ffmpeg 和样本，
  必须用打包脚本或 `tools\fetch-*.ps1`。
- **本仓库的 `origin` 是本机目录** `D:\git\FormatConverter.git`，新机器上没有。
  要么把那个目录一起拷过去（然后 `git remote set-url origin <新路径>`），
  要么换个远端（GitHub / 局域网路径 / U 盘裸库）。
- **`.ps1` 是 UTF-8 with BOM**：用编辑器改完要确认 BOM 还在，否则 PowerShell 5.1 按 ANSI 读，
  中文注释会把字符串吞掉，报"缺少右 }"这种看不懂的错。
- **壁纸不用搬**：程序读系统的 `TranscodedWallpaper` / `img0.jpg`；字体用系统字体。
- **快捷方式/卸载项不随文件走**：新机器上跑一次 `install.ps1` 就有了。
