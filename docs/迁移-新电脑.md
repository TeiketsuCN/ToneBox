# 把 ToneBox 工作区搬到另一台电脑

> 对应包：`E:\ToneBox-transfer-20261108.zip`（2026-11-08 深夜打包）。
> 目标：新机器上装好工具链 → 编译 → 安装 → 能继续开发，不用翻聊天记录。

## 0. 包里有什么

| 内容 | 说明 |
|---|---|
| `crates/` `docs/` `tools/` | 源码、全部文档/留言/交接记录、构建脚本 |
| `.git/` | 全部提交历史（main + `engine/*` 的 remote-tracking refs） |
| `vendor/ffmpeg/` | 随包 LGPL ffmpeg（152 MB），不用再下载 |
| `tools/rustup-init.exe` | 新机器装 Rust 用 |
| `samples/` | 44 个测试样本（打了 `-WithSamples` 才有，约 66 MB） |
| **不含** | `target/`（编译产物）、`out/`（截图/临时文件）、已安装的程序 |

`.ps1` 里带中文，**一律是 UTF-8 with BOM**；改脚本别把 BOM 弄丢。

## 1. 新机器：装工具链

### 1.1 Rust（必须是 gnu 工具链）

```powershell
.\tools\rustup-init.exe -y --default-host x86_64-pc-windows-gnu --profile minimal
```

已经装过 rustup 的话：

```powershell
rustup toolchain install stable-x86_64-pc-windows-gnu
rustup default stable-x86_64-pc-windows-gnu
```

### 1.2 MinGW（WinLibs）——gnu 目标要它的链接器

```powershell
winget install BrechtSanders.WinLibs.POSIX.UCRT
```

> `build.ps1` 现在会自己在
> `%LOCALAPPDATA%\Microsoft\WinGet\Packages\BrechtSanders.WinLibs.POSIX.UCRT_*\mingw64\bin`
> 里找 WinLibs，**不再写死用户名和盘符**，装完直接能用。

### 1.3 可选：ATRAC 外部编码器

```powershell
powershell -ExecutionPolicy Bypass -File tools\fetch-atracdenc.ps1
```

不随包分发（LGPL，且专利风险在分发端）；不装也能解码 ATRAC，只是不能转出。

## 2. 解压到哪

推荐 **`D:\FormatConverter`**——文档里的示例路径都按这个写。
放到别处也能用：`build.ps1` / `install.ps1` 都按脚本自身位置推项目根目录，
只有 `docs/` 里的历史示例会显得对不上。

## 3. 编译 + 安装

```powershell
cd <项目目录>
powershell -ExecutionPolicy Bypass -File tools\install.ps1
```

脚本会：release 构建 → 复制 exe 和 `vendor\ffmpeg` 到 `$AppDir` → 建桌面/开始菜单快捷方式（ToneBox）
→ 写卸载项 → 复制 `uninstall.ps1`。

`$AppDir` 默认 `D:\Apps\FormatConverter`；**没有 D 盘时**自动装到
`%LOCALAPPDATA%\Programs\FormatConverter`。想换地方就改 `tools\install.ps1` 里那一行。

## 4. 装完怎么验

1. 桌面 **ToneBox** 能打开，标题栏左边是 logo + 名字 + **铃铛**（有未读会亮红点）；
2. 拖一个音频进去：详情有码率/采样率/位深，质量评估会出结果；
3. 拖一个 **MKV / MP4** 进去：只取第一条音轨，导出成上面选的音频格式；
4. 输出列：压缩等级/采样率是**条**、「删除源文件」要**长按 3 秒**、转换时「开始转换」按钮里走进度；
5. 单元测试：

```powershell
cargo test -p fc-core --lib        # 42 个
cargo test -p fc-analyze           # 标定 + reference_values，约 70 秒，要 samples\
```

## 5. 可选：把用户配置带过去

复制旧机器的：

```
%APPDATA%\FormatConverter\config.json
```

到新机器同一位置。里面有配置 1/2/3、用户预设、界面缩放、HDR、库文件夹和库扫描缓存。

> 缓存里的路径（如 `D:\DSD`）在新机器上可能不存在——进「库」删掉旧目录，
> 重新「添加文件夹」+「重新扫描」即可。

## 6. 已知问题 / 别踩

- **别从旧机器拷 `target\`**：机器相关，容易出莫名其妙的链接错误；让它在新机器上重新编（首次约 2 分钟）。
- **`.ps1` 必须 UTF-8 with BOM**，否则 PowerShell 5.1 按 ANSI 读，中文注释会把字符串吞掉。
- **git 的 origin 是本机裸库** `D:\git\FormatConverter.git`，不会跟着 zip 走。
  新机器上要么把它一起拷过去再 `git remote set-url origin <新路径>`，要么换个远端（GitHub / 局域网）。
- **Rust 1.99 会刷 30 多条 `f32` 类型回退警告**（`Stroke::new(1.0, …)` 这类 future-incompat lint），
  目前不影响运行；`cargo fix` 能自动改大部分。
- **`atracdenc` 是 32 位程序**，非 ASCII 路径下出过问题；样本里全是日文名，用它转 ATRAC 时留意。
- **验证编码能力要用随包那份 ffmpeg**（`$AppDir\ffmpeg\ffmpeg.exe`），开发机 PATH 里那份编码器集合可能不一样。
